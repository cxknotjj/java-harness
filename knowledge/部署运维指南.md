# 部署运维指南

本文档属于公共知识库（default）：根目录散文档不属于任何子目录知识库，所有 agent 都可检索。

## 应用启动

```bash
mvn spring-boot:run
```

- 应用默认端口 8080，上下文路径为 `/`。
- 主库为 MySQL（Flyway 自动执行 `db/migration` 下的迁移），向量库为 PostgreSQL（pgvector）。
- PG 未就绪不影响启动：知识检索静默降级为空。

## 知识库同步

```bash
curl -X POST http://localhost:8080/api/knowledge/sync
```

增量摄取 `knowledge/` 目录下所有 `.md`/`.txt` 文档，仅 mtime 变更的文档重新嵌入。同步完成后可用调试检索验证：

```bash
curl 'http://localhost:8080/api/knowledge/search?q=部署步骤'
```

## 常见问题

- **知识库端点返回 503**：检查 `app.knowledge.enabled=true` 且 pgvector 与嵌入端点配置齐全。
- **检索无结果**：先执行 sync 摄取；确认 PostgreSQL 已启用 `vector` 扩展。
